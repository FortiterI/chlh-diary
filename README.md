# Щоденник ЧЛХ

Прототип генератора щоденників огляду для щелепно-лицевої хірургії.

## Походження
Початкова основа: [FortiterI/diary](https://github.com/FortiterI/diary), файл `index.html` із гілки `main` (під час створення копії). Оригінальний репозиторій не змінювався.

## Поточний стан
- Односторінковий HTML/CSS/JavaScript-прототип.
- Збережена основна логіка формування щоденників, додавання пацієнтів, імпорту та експорту.
- **Хмарне збереження та завантаження вимкнені.** Вбудований ключ JSONBin із початкового проєкту видалено з нової копії.
- **Не призначено для клінічного використання з реальними даними пацієнтів** до завершення аудиту безпеки та виправлення логіки формування медичних записів.

## Пріоритети розробки
1. Прибрати потенційні XSS: замінити вставку введених даних через `innerHTML` та inline-`onclick` на безпечні DOM API.
2. Виключити автоматичну генерацію випадкових життєвих показників для реальних медичних записів.
3. Прибрати автоматичне додавання непідтверджених клінічних тверджень (наприклад, про ПВК).
4. Налаштувати безпечне збереження даних, авторизацію та захист експорту. До цього використовувати лише вигадані/тестові дані.
5. Виправити збереження стану вікової групи та режимів генерації, а також `generateAll()`.
6. Переробити структуру записів для ЧЛХ: скарги, статус локаліс, рани та клапті, порожнина рота, дренажі, післяопераційна динаміка, призначення.
7. Додати автоматизовані тести та перевірки.

## Запуск
Відкрийте `index.html` у сучасному браузері. Для розробки та тестів використовуйте виключно вигадані дані.

## Примітка
Це окрема копія для подальшої роботи, а не завершена або перевірена медична система.
